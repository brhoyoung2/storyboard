뷰어 탭

유형/포즈 샘플 풀하우스 EP01 (입력↔출력) 20화 ↔ 원본 비교 캐릭터 시트 바디/포즈 (30종) 시점/각도 ✎ 직접 생성

입력 형식

  • 번호. [샷] 상황묘사 / 화자: "대사"
  • 샷: 풀샷 · 미들샷 · 클로즈업 · 롱샷
  • 인물 이름(매리·무결·엘리·라이더·정인 등) → 색·성별 자동 반영
  • “둘 / 서로” → 2명, “사람들” → 다인물, “(속마음)” → 생각 풍선, “효과음:” → 효과음

다른 실행 방법

  • python src/server.py — 웹앱(뷰어+실시간 생성). 가장 편함
  • python src/generate.py 내콘티.txt — 파일 1개 → SVG 1장 (.pdf도 가능)
  • python src/batch_generate.py — data의 20화 일괄 생성

* 손그림 떨림 필터와 손글씨 폰트는 브라우저(크롬)에서만 보입니다.
